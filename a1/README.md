# A1 — Anfänger

## 🎯 Lernziele — Was ich kann

Nach A1 kann ich:

- [ ] mich vorstellen und andere begrüßen
- [ ] über meine Familie und Freunde sprechen
- [ ] im Café und Restaurant bestellen
- [ ] einkaufen und nach dem Preis fragen
- [ ] über meinen Alltag sprechen (Tagesablauf, Uhrzeit)
- [ ] einfache Sätze im Präsens bilden
- [ ] die Artikel (der/die/das) der wichtigsten Nomen
