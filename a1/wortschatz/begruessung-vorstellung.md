# Begrüßung & Vorstellung

## 👋 Begrüßung

| Deutsch | Beispiel |
|---|---|
| Guten Morgen! | Guten Morgen, Anna! |
| Guten Tag! | Guten Tag, Herr Schmidt! |
| Guten Abend! | Guten Abend zusammen! |
| Hallo! / Hi! | Hallo, wie geht's? |
| Tschüss! | Tschüss, bis morgen! |
| Auf Wiedersehen! | Auf Wiedersehen, Frau Meyer! |
| Bis später! | Bis später! |

## 🙋 Vorstellung

| Deutsch | Beispiel |
|---|---|
| Ich heiße … | Ich heiße Osama. |
| Ich bin … | Ich bin Student. |
| Ich komme aus … | Ich komme aus Pakistan. |
| Ich wohne in … | Ich wohne in Chemnitz. |
| Wie heißt du? | Wie heißt du? — Ich heiße Sara. |
| Woher kommst du? | Woher kommst du? — Aus Syrien. |
| Wo wohnst du? | Wo wohnst du? — In Berlin. |
| Freut mich! | Freut mich, dich kennenzulernen! |
| Wie geht's? | Wie geht's dir? — Gut, danke! |

## 📝 Wichtige Nomen

| Deutsch | Artikel | Plural | Beispielsatz |
|---|---|---|---|
| Name | der | die Namen | Mein Name ist Osama. |
| Nummer | die | die Nummern | Meine Nummer ist 0152… |
| Adresse | die | die Adressen | Was ist deine Adresse? |
| Telefon | das | die Telefone | Das Telefon klingelt. |
| E-Mail | die | die E-Mails | Ich schreibe eine E-Mail. |
| Sprache | die | die Sprachen | Deutsch ist eine schwere Sprache. |
| Land | das | die Länder | Pakistan ist mein Land. |
| Stadt | die | die Städte | Chemnitz ist eine schöne Stadt. |
| Mann | der | die Männer | Der Mann heißt Ali. |
| Frau | die | die Frauen | Die Frau ist nett. |
| Kind | das | die Kinder | Das Kind spielt. |
| Freund | der | die Freunde | Er ist mein Freund. |
| Freundin | die | die Freundinnen | Sie ist meine Freundin. |
| Beruf | der | die Berufe | Was ist dein Beruf? |
| Arbeit | die | die Arbeiten | Die Arbeit ist interessant. |
| Frage | die | die Fragen | Ich habe eine Frage. |
