# Nominativ und Akkusativ

## 📖 Erklärung

- **Nominativ** = Wer oder was? → das **Subjekt**
- **Akkusativ** = Wen oder was? → das **direkte Objekt**

Nur die **maskulinen** Artikel ändern sich im Akkusativ!

## 📊 Übersicht

| | Nominativ | Akkusativ |
|---|---|---|
| maskulin | der / ein Mann | **den** / **einen** Mann |
| feminin | die / eine Frau | die / eine Frau |
| neutral | das / ein Kind | das / ein Kind |
| Plural | die Männer | die Männer |

## 💬 Beispielsätze

1. Der Mann kauft **einen** Apfel. *(Wer? Der Mann. Wen? Einen Apfel.)*
2. Die Frau liest **ein** Buch.
3. Das Kind trinkt **die** Milch.
4. Ich sehe **den** Hund.
5. Du hast **eine** Katze.
6. Er trinkt **einen** Kaffee.
7. Wir kaufen **das** Brot.
8. Sie schreibt **einen** Brief.

## ✏️ Mini-Übung

Setze ein: **den / einen / die / eine / das / ein**

1. Ich sehe ___ Mann.
2. Sie kauft ___ Banane.
3. Er liest ___ Buch.
4. Wir haben ___ Auto.
5. Du trinkst ___ Tee.

<summary>Lösungen</summary>

1. den Mann
2. eine Banane
3. ein Buch
4. ein Auto
5. einen Tee
