# Pluralbildung

## 📖 Erklärung

Die Plural-Regeln muss man lernen — aber es gibt ein System! Hier sind die wichtigsten Regeln:

## 📊 Übersicht

| Regel | Beispiel |
|---|---|
| 1. **+ -e** | der Tisch → die Tische |
| 2. **+ -er** (oft mit Umlaut) | das Kind → die Kinder |
| 3. **+ -n / -en** | die Frau → die Frauen |
| 4. **+ -s** (Fremdwörter) | das Handy → die Handys |
| 5. **nur Umlaut** (ä, ö, ü) | der Vater → die Väter |
| 6. **keine Änderung** | der Computer → die Computer |

## 📝 Beispiele pro Regel

**Regel 1 (+ -e):** der Stuhl → die Stühle · das Brot → die Brote
**Regel 2 (+ -er):** das Buch → die Bücher · das Haus → die Häuser
**Regel 3 (+ -n/-en):** die Lampe → die Lampen · die Tasse → die Tassen
**Regel 4 (+ -s):** das Auto → die Autos · das Sofa → die Sofas
**Regel 5 (Umlaut):** die Mutter → die Mütter · der Bruder → die Brüder
**Regel 6 (gleich):** das Zimmer → die Zimmer · der Löffel → die Löffel

## 💬 Beispielsätze

1. Die Tische sind neu.
2. Die Kinder spielen.
3. Die Frauen sprechen Deutsch.
4. Die Autos sind teuer.
5. Meine Brüder wohnen in Berlin.
6. Die Zimmer sind groß.
